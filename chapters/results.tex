\subsection{Subsonic MHD Turbulence}

Application. DivB error + resistive heating. 

Large-scale mean field, mildly super-alfvenic. $B=B_0\hat{z}$ with $B_0 = 0.15$. 

\begin{equation}
    \beta = \frac{P_{gas}}{P_{mag}} = \frac{\rho c^2}{B_0^2 / 2 \mu_0} \Rightarrow B_0 = \sqrt{2 \rho c^2 / \beta}
\end{equation}

Plasmabeta $\beta$. Sound speed $c=1$, Alfvén speed $v_A = \frac{|B|}{\sqrt{\mu_0 \rho}}$. $v_{RMS} = 0.3$ (subsonic). Sonic mach number $M = \frac{v_{RMS}}{c} = 0.3$. Alfvenic mach number $M_A = \frac{v_{RMS}}{v_A}=2$ (>1, super-alfvenic, turbulence dominates).
