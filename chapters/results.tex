\section{Numerical Tests}
In this chapter we present the results produced by SPH-EXA on a suite of standard MHD tests. With the first seven test cases we verify that our implementation produces results comparable to the reference codes \cite{WissingShen2020, Price2018}. We quantify accuracy and other relevant metrics such as the mean divergence error \eqref{eq:divb_error} and magnetic energy loss through artificial resistivity (resistive heating). Finally, in §\ref{sec:mhd_turb}, we apply a magnetic field to subsonic turbulence in a high-resolution simulation.

All tests are set up with glass-like initial conditions using the template glass blocks from SPH-EXA's public dataset \cite{Keller2023}. This is to be kept in mind when comparing SPH-EXA to codes using lattice-based initial conditions. The glass structure necessarily comes with some jittering due to particle reordering, resulting in a small but noticeable velocity noise floor. This will negatively impact certain tests which otherwise have almost perfectly uniform flow when using a lattice (e.g. the MHD advection loop §\ref{sec:MHD_loop}). 

For some MHD tests we did create initial conditions using both a regular grid and a face-centered cubic (FCC) grid. However, in our runs we see the lattices quickly melting into glass after only a few time steps. This is likely due to the kernel design choices of SPH-EXA, namely using a constant number \texttt{ng0} for the target number of neighbors combined with the sinc6 kernel (§\ref{sec:kernel_approximation}). A different kernel implementation should be able to keep a lattice structure and therefore uniform flow intact in SPH-EXA, but this is out of scope for this project.

Considering the presence of this velocity noise, we also expect the divergence error of most tests to be slightly larger than the corresponding references. Velocity noise enters the divergence error as one of the dominant source through the discrete induction equation, which is built from the velocity gradient tensor \eqref{eq:induction_code}. 

Whenever we refer to a resolution (e.g. $n_x = 250$) of a simulation using glass blocks, we refer to the resolution along the axes of the original grid with which the glass was generated. I.e. our glass block \texttt{50c.h} (read "50 cubed") was created from a $50 \times 50 \times 50$ lattice. The total number of particle remains the same, but they do not remain well ordered in the axis direction.

If not explicitly written otherwise, the test setups use the following default parameters. We use the sinc6 smoothing kernel with \texttt{ng0=150} desired neighbors per particle. AV uses AVSLR with constant $\alpha = 1.0$ (see §\ref{sec:slr}). And so does AR with ARSLR and $\alpha_B=1.0$. Magnetic constant $\mu_0 = 1$. \paragraph{Naming of AR schemes}
For simplicity we label the baseline scheme, using constant $\alpha_B = 0.5$, in our figures as \texttt{a05}. The schemes employing reconstruction as introduced in §\ref{sec:slr} are labelled \texttt{SLR}, \texttt{SLRB} and \texttt{SLRB2} respectively. All AR schemes use the self-switching $v_{sig,B}$ as defined in \eqref{eq:vsigB}.

\paragraph{Plotting Method}
The two-dimensional slices plotted in the following sections are created with the following method: A particle $i$ is only selected if its distance to the slice plane is smaller than $2h_i$, i.e. the plane actually falls inside its kernel support. Then the selected particles are interpolated onto a regular grid of $512 \times 512$ pixels. Pixel values are calculated with the normalized SPH sum $ {\sum f_i W(r_{ip}/ h_i)}/{\sum W(r_{ip}/h_i)}$, where $W$ is the cubic spline kernel, $h_i$ the particle's smoothing length, and $r_{ip}=|r_i-r_p|$ the full 3D distance between the particle and the pixels center (including out-of-plane offset). This way of selection and interpolation tries to stay as close as possible to the actual physical representation.

\subsection{Alfvén Wave}
We perform the traveling circularized polarized (CP) Alfvén wave test \cite{Toth2000} which provides an analytical solution to the ideal MHD equations. Because the magnetic pressure is uniform, the wave is expected to remain the same after each period. Deviation is a good measurement of numerical dissipation and dispersion. 

The 3D setup follows the one in used in PHANTOM \cite{Price2018} and GASOLINE2 \cite{WissingShen2020}: A periodic box of size $L\times L/2 \times L/2$ with $L=3$ with the waves traveling at a $30^\circ$ angle to the $x$ axis get a true multidimensional test of the full 3D operators. The rotated parallel and transverse velocities and magnetic fields are: 

$ B_1 = 1, v_1 = 0\\
B_2 = v_1 = 0.1 \sin(2\pi x_1/\lambda), \\
B_3 = v_2 = 0.1 \cos(2\pi x_1/\lambda), $

where $x_1$ is the rotated direction of propagation and $\lambda=1$ is the wavelength. We use density $\rho = 1$ and uniform pressure $P=0.1$. Figure \ref{fig:alfven} shows the results after $t=5$ periods using $[n_x,n_y,n_z]=[120,60,60]$. We also plot the L1-error with increasing resolution and observe second-order convergence as expected. As per default parameters, all dissipation mechanisms (bar conductivity) are active.

\paragraph{Noisy Alfvén Wave}
We present a slight modification of the Alfvén wave test, not present in the reference literature, specifically to evaluate the performance of ARSLR. Additionally to the classic setup defined above, we add positionally-seeded white-noise perturbation to the magnetic field $B$ and velocity field $v$ in the initial conditions. With this we aim to observe how different dissipation schemes tackle incoherent noise (unresolved structure) versus the coherent wave (resolved structure). As described in §\ref{sec:slr}, the hope for ARSLR is to use full dissipation on the former while being able to linearly reconstruct and thus preserve the latter. 

To quantify this we perform a least-squares fit of the mode to both transverse components $B_2$ and $B_3$, and decompose the error into three errors: 
\begin{itemize}
    \item Amplitude bleed: The ratio $A/A_0$ of the fitted mode amplitude to the initial $A_0=0.1$ to isolate resolved structure dissipation. 
    \item Phase error: The fitted phase minus the analytic phase to isolate dispersion. 
    \item $\delta B_n$: RMS of the mode subtracted transverse field to measure how fast the seeded white noise is cleaned up. 
\end{itemize}

\subsection{Subsonic MHD Turbulence}
\label{mhd_turb}

Application. DivB error + resistive heating. $1600^3$ particles (more than 4 billion). 

Large-scale mean field, mildly super-alfvenic. $B=B_0\hat{z}$ with $B_0 = 0.15$. 
gamma=1.001

\begin{equation}
    \beta = \frac{P_{gas}}{P_{mag}} = \frac{\rho c^2}{B_0^2 / 2 \mu_0} \Rightarrow B_0 = \sqrt{2 \rho c^2 / \beta}
\end{equation}

Plasmabeta $\beta$. Sound speed $c=1$, Alfvén speed $v_A = \frac{|B|}{\sqrt{\mu_0 \rho}}$. $v_{RMS} = 0.3$ (subsonic). Sonic mach number $M = \frac{v_{RMS}}{c} = 0.3$. Alfvenic mach number $M_A = \frac{v_{RMS}}{v_A}=2$ (>1, super-alfvenic, turbulence dominates).
